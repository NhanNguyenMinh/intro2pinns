Cài môi trường một lần

Cài Anaconda Distribution hoặc Miniconda, rồi mở Anaconda Prompt. Đây là cửa sổ CMD có sẵn lệnh conda. Chuyển đến thư mục này và tạo môi trường riêng:

cd /d DUONG_DAN_DEN_REPO\learn-python
conda env create -f environment.yml
conda activate intro2pinns-learning
python --version
where python

Dòng đầu của where python cần nằm trong môi trường mới. Bài 04 cần PyTorch: trên trang cài đặt chính thức, chọn Stable · Windows · Pip · Python · CPU và chạy lệnh được hiển thị khi môi trường đang kích hoạt.

CMD thường: nếu lệnh conda chưa được nhận, dùng Anaconda Prompt trước. Để dùng CMD thông thường, cấu hình conda theo hướng dẫn chính thức rồi mở lại cửa sổ CMD.
