Học và cùng sửa notebook trên Google Colab

Colab giúp cả nhóm đọc, chú thích và chỉnh sửa cùng một notebook qua Google Drive. Mỗi người vẫn chạy mã trong một runtime riêng; nhóm cần lưu kết quả và phiên bản code rõ ràng.

Google Drive để cộng tácGitHub giữ bản chuẩnRuntime riêng cho từng người

Mở notebook

Hai cách bắt đầu

  1. Từ GitHub

    Mở một notebook ở bảng bên dưới. Nếu notebook trên GitHub chỉ có quyền đọc, vào menu File → Save a copy in Drive để tạo bản có thể sửa; đặt tên nhóm và số bài rõ ràng.

  2. Từ file trên máy

    Truy cập colab.research.google.com, chọn File → Upload notebook, rồi chọn file .ipynb trong thư mục learn-python. Dùng cách này nếu repo chưa được cập nhật.

Chia sẻ

Một notebook Drive cho nhóm, phân công rõ người sửa

  1. Tạo bản làm việc

    Một bạn lưu notebook vào Google Drive và đổi tên theo mẫu nhom-pinns_bai-03_fem.ipynb. Bản GitHub là ví dụ gốc để đối chiếu.

  2. Mời đúng ba thành viên

    Nhấn Share ở góc trên bên phải, nhập địa chỉ Google của hai bạn còn lại và chọn quyền Editor. Giữ quyền truy cập chung ở mức Restricted nếu không cần công khai.

  3. Phân công trước khi sửa

    Mỗi bạn nhận một phần: ví dụ, người A kiểm tra mô hình và điều kiện biên, người B viết/kiểm tra code, người C làm bảng và nhận xét. Ghi tên người phụ trách trong ô Markdown đầu notebook. Tránh cùng lúc sửa một ô code dài.

  4. Chốt một phiên bản chạy được

    Sau khi ghép nội dung, một bạn chạy Runtime → Restart and run all (hoặc lệnh tương đương trong giao diện hiện tại), sửa lỗi theo thứ tự ô, rồi ghi ngày, seed và phiên bản thư viện. Tải file .ipynb về và đưa bản đã kiểm tra lên GitHub.

Phân biệt hai việc: mọi người có thể cùng xem/sửa nội dung notebook được chia sẻ, nhưng mỗi người có bộ nhớ, file tạm và gói cài đặt của runtime riêng. Một hình hoặc CSV tạo trong runtime của bạn A không tự xuất hiện trong runtime của bạn B.

Chạy được trên Colab

Kiểm tra môi trường và file phụ thuộc

Trong một ô đầu notebook, chạy:

import sys, numpy, scipy, sympy, torch
print(sys.version)
print('numpy', numpy.__version__, 'scipy', scipy.__version__)
print('sympy', sympy.__version__, 'torch', torch.__version__)

Các notebook 01–02 tự chứa phần tính toán chính. Notebook 05 tự chứa mã; notebook 03–04 gọi các script .py cùng thư mục. Khi chạy trên Colab, ô chuẩn bị của hai notebook này sẽ tải repo vào runtime nếu chưa có file script. Nếu nhóm sửa script trong Drive, phải tải hoặc đồng bộ script đó vào runtime nữa; chỉ sửa notebook không làm thay đổi bản trên GitHub.

Nếu thiếu thư viện, thêm ô %pip install ten-goi ở đầu notebook rồi khởi động lại runtime khi được yêu cầu. Không giả định máy của các bạn có cùng phiên bản thư viện; ghi phiên bản trong báo cáo. Bài dầm 1D dùng CPU là đủ để học các bước đầu.

Quy trình nhóm đề xuất

Drive để thử ý tưởng, GitHub để chốt kết quả

1 · Bản nháp chung trên Drive

Thử các biến thể, chú thích câu hỏi, phân công ô. Mỗi thay đổi số học phải kèm tham số, seed và nhận xét.

2 · Bản chuẩn trên GitHub

Chỉ đưa lên bản đã chạy lại từ đầu. Giữ script .py làm phiên bản có thể tái lập; notebook là tài liệu giải thích và trình bày.

3 · Lưu minh chứng

Giữ đồ thị, bảng sai số và tệp kết quả cần thiết trong báo cáo. Dữ liệu trong /content của Colab là tạm thời.

4 · Bảo vệ Drive cá nhân

Chỉ dùng drive.mount() khi bài thực sự cần file Drive. Code trong notebook có quyền truy cập Drive sau khi bạn cấp quyền, nên đọc code trước khi cho chạy.

Bài tập khởi động nhóm: mỗi bạn mở bài 01 trên Colab, chạy toàn bộ ô, sửa tải q=2 và ghi dự đoán trước khi chạy. Một bạn tạo bản Drive chung, mời hai bạn còn lại chỉnh sửa, rồi cả nhóm chốt một notebook chạy được từ đầu và một đoạn nhận xét 5–7 câu.
