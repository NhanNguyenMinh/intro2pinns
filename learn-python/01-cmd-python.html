Viết một script thực sự chạy được để tính chuyển vị của dầm. Sau bài này, bạn biết tự mở môi trường, chạy file Python và kiểm tra kết quả số.

Mục tiêu

Chạy được bằng Command Prompt

Mở Anaconda Prompt (một cửa sổ CMD đã nhận diện conda). Trong thư mục bài học, thử lần lượt:

cd /d DUONG_DAN_DEN_REPO\learn-python

conda activate intro2pinns-learning

python 01-cmd-python.py

cd /d đổi cả thư mục và ổ đĩa; dir liệt kê file; where python cho biết Python nào đang chạy. Nếu có nhiều Python trên máy, hãy kiểm tra dòng đầu tiên của where python.

Thử thật: chạy lại script sau khi đóng và mở một cửa sổ CMD mới. Bạn phải kích hoạt môi trường trong cửa sổ mới trước khi chạy.

Bài toán xuyên suốt

Hàm chuyển vị giải tích

w(x)=q₀(x⁴−2Lx³+L³x)/(24EI),   0≤x≤L

Script tạo một hàm nhận x, length, bending_stiffness, load; trả về w(x). Bắt đầu bằng bản ngắn:

def beam_deflection(x, length=1.0, bending_stiffness=1.0, load=1.0):
    return load * (x**4 - 2*length*x**3 + length**3*x) / (24*bending_stiffness)

for i in range(11):
    x = i / 10
    print(f"{x:.2f}  {beam_deflection(x):.8f}")

Đọc script hoàn chỉnh để xem thêm kiểm tra đầu vào, điều kiện if, từ điển tham số và cách dùng if __name__ == "__main__":. Dùng notebook bài 01 để chạy từng ô.

Tự làm

Ba phép kiểm tra bắt buộc

  1. Điều kiện biên

    Kiểm tra w(0)=w(L)=0 bằng code. Giải thích vì sao chỉ hai phép thử này chưa đủ để chứng minh công thức đúng.

  2. Giữa dầm

    Với L=EI=q₀=1, kiểm tra w(L/2)=5/384≈0.01302083. So với bảng script in ra.

  3. Đổi tham số

    Giữ x/L=1/2. Tăng q₀ gấp đôi, tăng EI gấp đôi, rồi tăng L gấp đôi. Dự đoán tỉ lệ thay đổi trước khi chạy và giải thích bằng công thức.
